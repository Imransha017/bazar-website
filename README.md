# Website Launch Guardian

আমি আমার ওয়েবসাইটের সম্পূর্ণ কোডের জিফ ফাইল তোমাকে দিয়েছি আমার এই ওয়েবসাইটটি এখন পাবলিশ করব Lovable এ এখন তুমি এই কাজটি করো কিন্তু খুব সতর্ক lovable ai এ"Try to fix" ফিচার অপশনে ক্লিক করে কখনই ফিক্স করবে না সমাধান কোড পরিবর্তন করে তুমি ফিক্স করবে ঠিক আছে কারণ এর আগে এই "Try to fix" অপশনটি ক্লিক করে ফিক্স করার কারণে আমার প্রচুর পরিমাণে ক্রেডিট নষ্ট হয়েছে আমার একাউন্ট প্রজেক্ট ব্লক করে দিয়েছে Lovable থেকে। তাই এরকম যেন না হয় খুব সতর্ক থাকবে
